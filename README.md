## 🛠 Stack Technique
- **Framework :** Next.js 14 (App Router)
- **UI & Logique :** React 18 & TypeScript
- **Styling :** Tailwind CSS
- **Typographie :** Inter (Google Fonts optimisée via `next/font`)
- **Icônes :** Lucide React
- **SEO & Métadonnées :** Open Graph, Twitter Cards, balises sémantiques HTML5, `robots.ts`, `sitemap.ts`, schéma JSON-LD Schema.org (`ProfessionalService`)

## 🚀 Démarrage Rapide

### 1. Développement local
```bash
npm run dev
```
Ouvrez `http://localhost:3000` dans votre navigateur.

### 2. Compilation de production
```bash
npm run build
npm run start
```
